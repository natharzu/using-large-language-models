# data/

Place datasets here. This folder is **git-ignored** (except this file), so large or private data is never committed.

## Suggested datasets

| Use case | Dataset idea |
| --- | --- |
| Sentiment (Ch. 4–5) | Amazon product reviews with star ratings |
| Language modeling (Ch. 3) | Congressional speeches / parliamentary debates |
| Classification (Ch. 5, capstone) | News headlines, party manifestos |
| Retrieval & RAG (Ch. 14) | A small corpus of policy documents |
| Annotation (capstone) | A few hundred manually labeled sentences |

## Tips

- Keep a small sample committed elsewhere if you want reproducibility, but never commit large or copyrighted corpora.
- Document the source and license of each dataset you download.
