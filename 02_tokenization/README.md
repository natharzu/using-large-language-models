# Chapter 2 — Tokenization

> J&M *Speech and Language Processing*, Ch. 2 (Regular Expressions, Text Normalization, Edit Distance).

Before a model can do anything with text, the text must be split into **tokens**. This chapter is about how that split is made and why it matters.
