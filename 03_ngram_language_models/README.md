# Chapter 3 — N-gram Language Models

> J&M *Speech and Language Processing*, Ch. 3 (N-gram Language Models).

The original language models: estimate the probability of the next word from counts of the previous *n–1* words. Simple, fast, and the conceptual root of everything that follows.
